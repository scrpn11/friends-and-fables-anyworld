# Incarnation

## Description

Incarnation is a neutral race entry used when Anyworld requires every character to have a race. It does not define anatomy, species, culture, lifespan, senses, movement, abilities, or social identity. Those traits come from the selected world and the current incarnation's character or race files. Base speed is 30 feet. Ability-score bonuses are +1 to three different scores chosen for the incarnation.
