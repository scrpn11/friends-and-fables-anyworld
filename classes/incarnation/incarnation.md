# Incarnation

### Description

Incarnation is the universal class assigned to every life created through The Between. It does not represent a profession, combat discipline, social role, power system, or canon identity. Instead, it provides a neutral mechanical frame that can be interpreted through the selected world's rules. All meaningful abilities, training, powers, limitations, equipment, and progression come from the current incarnation and setting rather than from this class itself.

**Hit Die:** 1d8  
**Choose Subclass at Level:** None  
**Is Spellcaster:** No  
**Spellcasting Ability:** None  
**Spell Preparation Type:** None  
**Spellcasting Type:** None

## Class Features

Incarnation has no universal class features. Do not invent generic attacks, proficiencies, spells, resistances, social privileges, supernatural traits, or setting-independent powers for it. When a world requires a class entry, use Incarnation only as a neutral container. Record all actual capabilities on the character sheet, in setting-specific subclasses, or in world-specific race, role, item, spell, or lore files. If the selected world uses no class system, leave the subclass blank and allow the character's established canon identity, occupation, training, species, powers, and circumstances to define play. If the world does use classes, schools, ranks, professions, archetypes, or power categories, represent those separately without changing Incarnation into a universal fantasy class. This class must never override canon, grant continuity between lives, preserve memories, or imply that reincarnated characters share hidden abilities. Each new life begins with only the traits deliberately chosen for that incarnation and supported by its world.
