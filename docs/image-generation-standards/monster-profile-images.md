# Creature and Monster Profile Image Standards

Use this standard for animals, monsters, spirits, constructs, aliens, transformed people, and other creatures.

Read the creature Markdown and global standards in full. Identify the exact selected world, continuity, timeline, and source medium. Research authoritative references for canonical species, monsters, forms, and effects before generating.

## Copy-Ready Prompt Template

```text
Create a square 1:1 creature profile image for Anyworld using [PATH OR NAME OF CREATURE OR MONSTER MARKDOWN] as the repository source of truth.

Match the selected world's authoritative medium and preserve the creature's canonical anatomy, proportions, size, number of limbs, covering, coloration, posture, movement, attacks, equipment, forms, and supernatural behavior. Use the correct continuity and point in the timeline. Do not merge designs from incompatible adaptations, evolutions, transformations, or later forms.

Show the complete creature in a view that makes its anatomy, scale, movement, and defining traits readable. Follow official bestiary, character-sheet, Pokédex, game-render, manga, anime, comic, or cinematic presentation conventions when they exist. Otherwise use a simple atmospheric background that does not obscure the subject.

Optional override for this image only: [NONE]

No text, labels, logos, UI, signatures, watermarks, random horns, wings, eyes, armor, demonic traits, glow, gore, extra limbs, duplicated anatomy, cropped defining features, incompatible forms, unrelated victims, or any contradiction of the Markdown or canon.
```
