# Species, Race, and People Profile Image Standards

Use this standard for species, races, peoples, lineages, and other shared biological or cultural identities.

Read the relevant Markdown and global standards in full. Do not assume a fantasy race, humanoid adult, medieval clothing, or a single representative body plan. For established fiction, research the exact continuity, era, and authoritative visual depictions before generating.

## Copy-Ready Prompt Template

```text
Create a square 1:1 profile image for the species, race, people, or lineage defined in [PATH OR NAME OF MARKDOWN].

Identify the selected world, continuity, timeline, and source medium. Match its authoritative art direction and preserve established anatomy, scale, variation, skin or covering, limbs, facial structure, sensory organs, markings, adaptations, clothing conventions, technology, culture, and innate abilities.

Choose a presentation that reflects official source material. A single representative figure is appropriate only when it does not falsely imply that all members share one sex, age, body type, occupation, caste, costume, or appearance. Use multiple figures or another composition when necessary to communicate canonically important variation.

Where canon is incomplete, make only conservative in-world inferences. Do not add generic elf ears, horns, tails, wings, fangs, armor, jewelry, weapons, or magical effects unless supported.

Optional override for this image only: [NONE]

No text, labels, logos, UI, signatures, watermarks, incompatible adaptation details, invented biological traits, culturally misleading universal costumes, unsupported powers, distorted anatomy, cropped defining features, or any contradiction of the Markdown or canon.
```
