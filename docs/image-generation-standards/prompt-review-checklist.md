# Prompt Review Checklist

Use this checklist before generating, accepting, revising, or committing a Kato image.

## Before Generating

- Select the exact category prompt: character, monster, item, area, or POI.
- Replace every bracketed field that materially affects the image.
- Remove unused optional fields rather than leaving contradictory placeholders.
- Check the written entry and all established reference images.
- Identify details that must not change: age, build, face, outfit, anatomy, scale, object silhouette, location layout, materials, magical behavior, lighting, and mood.
- Use full-body composition for character profiles unless another crop is explicitly requested.
- Use a neutral profile background for characters, monsters, and items; use a complete scene for areas and POIs.

## Required Consistency

Every completed prompt must retain the fixed Kato language for:

- square 1:1 format;
- polished, clearly 2D dark-anime fantasy art;
- clean confident linework;
- controlled cel shading;
- restrained painterly detail;
- readable silhouettes;
- cold, ancient, isolated, mysterious, dangerous, melancholic, slightly dreamlike atmosphere;
- restrained northern palette;
- cinematic but readable lighting;
- no text or interface elements;
- category-specific fidelity and negative requirements.

Do not shorten the fixed art-direction or negative-requirement sections merely because the subject details are simple. Their repetition is intentional and preserves visual consistency.

## Failure Checks

Reject or revise an image if it has text, watermarks, fake letters, wrong age or build, changed facial identity, cropped footwear or anatomy, incorrect object silhouette, incorrect creature scale, extra limbs, unrelated magic, generic scenery, changed location layout, modern objects, photorealism, western fantasy rendering, glossy 3D appearance, chibi proportions, unreadable darkness, excessive fog, neon overload, or generic AI-fantasy decoration.

Kato art must read clearly as polished 2D dark anime at first glance. Mystery and dreamlike atmosphere should come from lighting, fog, negative space, distance, and restrained surreal details—not from obscuring the subject.

## Copy-Ready Revision Prompt

Replace the bracketed fields and preserve the rest.

```text
Revise the attached Kato image with a targeted correction only.

PRESERVE EXACTLY
[LIST EVERYTHING THAT MUST NOT CHANGE: SUBJECT IDENTITY, FACE, BUILD, POSE, CLOTHING, ANATOMY, OBJECT SHAPE, LOCATION LAYOUT, CAMERA, LIGHTING, BACKGROUND, ART STYLE, ETC.]

CHANGE ONLY
[DESCRIBE THE SINGLE CORRECTION OR SMALL SET OF RELATED CORRECTIONS]

Keep the image square 1:1. Preserve the polished, clearly 2D dark-anime Kato style with clean confident linework, controlled cel shading, restrained painterly detail, readable silhouettes, cinematic lighting, a restrained northern palette, and a cold, ancient, isolated, mysterious, melancholic, slightly dreamlike atmosphere.

Do not broadly redesign or regenerate unrelated details. No text, captions, labels, logos, borders, UI, signatures, watermarks, fake letters, photorealism, western fantasy realism, chibi style, 3D-render appearance, modern objects, sci-fi elements, random runes, unrelated weapons, extra limbs, distorted hands, mismatched eyes, excessive glow, or changes beyond the requested correction.
```

## Acceptance Standard

Accept an image only when it is useful in play, faithful to the written entry, consistent with Kato's exact art direction, readable at interface size, and unlikely to mislead players or the AI GM.
