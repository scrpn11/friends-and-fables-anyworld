# Prompt Review Checklist

Use this checklist before generating, accepting, revising, or committing an Anyworld image.

## Source and Continuity

- Identify the exact world, continuity, adaptation, and point in the timeline.
- Identify the intended medium: anime, manga, game, comic, film, television, illustrated prose, or original setting.
- Research authoritative visual references for established fiction.
- Do not mix incompatible adaptations, costumes, forms, powers, or later-era designs.
- Treat fan art as secondary interpretation, never as canon authority.

## Written Fidelity

- Read every supplied Markdown file in full.
- Preserve all explicit player choices, including deliberate departures from canon norms.
- Check age, build, anatomy, face, clothing, equipment, role, powers, scale, object silhouette, and location layout.
- Make only small conservative inferences where both canon and the repository are silent.
- Reject invented lore or visuals that materially change the selected world.

## Visual Fidelity

- The result should be recognizable as belonging to the selected source at first glance.
- Match its proportions, linework, rendering, palette behavior, costume language, architecture, technology, effects, and presentation.
- Do not default to dark fantasy, generic anime, western realism, photorealism, chibi, or glossy 3D unless that matches the source or the player requests it.
- Keep the subject readable at Friends & Fables interface size.

## Failure Checks

Reject or revise an image with the wrong continuity, wrong era, mixed adaptations, changed identity, anachronistic technology, unsupported clothing or powers, invented anatomy, incorrect scale, cropped defining features, unrelated props, text, watermarks, fake lettering, extra limbs, distorted hands, or a generic style that erases the selected world's identity.

## Copy-Ready Revision Prompt

```text
Revise the attached Anyworld image with a targeted correction only.

SELECTED WORLD, CONTINUITY, TIMELINE, AND MEDIUM
[IDENTIFY EACH]

PRESERVE EXACTLY
[LIST EVERYTHING THAT MUST NOT CHANGE]

CHANGE ONLY
[DESCRIBE THE CORRECTION]

Preserve the selected source's authoritative visual language and every established Markdown detail. Do not broadly redesign unrelated elements or introduce details from another adaptation, era, or generic art style.

No text, captions, labels, logos, borders, UI, signatures, watermarks, fake lettering, unrelated props, accidental identity changes, extra limbs, distorted anatomy, or changes beyond the requested correction.
```

## Acceptance Standard

Accept an image only when it is useful in play, faithful to the player's choices and repository entries, consistent with the chosen world's canon and source medium, readable at interface size, and unlikely to mislead the player or GM.
