# Item Image Standards

Use this standard for weapons, clothing, armor, tools, devices, vehicles, relics, consumables, materials, and other objects.

Read the item Markdown and global standards in full. Identify the exact selected world, continuity, timeline, and source medium. Research authoritative references when the object or its technology belongs to established fiction.

## Copy-Ready Prompt Template

```text
Create a square 1:1 item profile image for Anyworld using [PATH OR NAME OF ITEM MARKDOWN] as the repository source of truth.

Match the selected world's authoritative visual medium and the object's canonical design, technology level, materials, construction, scale, condition, ornamentation, and effects. Preserve the exact object type and silhouette. When canon is silent, make only small in-world inferences; do not turn an ordinary item into an ornate fantasy relic or futuristic device.

Show the complete item clearly using the kind of presentation associated with official item art for the selected property. If no convention exists, center it against a simple unobtrusive background with a subtle grounding shadow. Do not show a user or action scene unless requested.

Optional override for this image only: [NONE]

No text, labels, logos, UI, signatures, watermarks, incompatible adaptation details, anachronistic manufacturing, random gems, runes, spikes, gold trim, glow, added moving parts, incorrect scale, cropped edges, unrelated props, or any contradiction of the Markdown or canon.
```
