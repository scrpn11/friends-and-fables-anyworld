# Character Profile Image Standards

Use this standard for player characters and NPCs in any selected world.

## Required Output

- Square 1:1 image unless another format is requested.
- Full body from head to feet unless a different crop is requested.
- One clearly readable character.
- Background and presentation appropriate to the selected world's official character art.
- No text.

Read the character Markdown and any relevant race, class, role, equipment, or incarnation files in full. For established fiction, identify the exact continuity, era, and adaptation, then research authoritative visual references. The selected world's canon and medium determine anatomy conventions, facial construction, clothing design, technology, magic effects, linework, rendering, and presentation.

A player may deliberately choose traits or circumstances that differ from canon norms. Preserve those explicit choices, but do not create unrelated contradictions.

## Copy-Ready Prompt Template

```text
Create a square 1:1 full-body character profile image for Anyworld using [PATH OR NAME OF CHARACTER MARKDOWN] as the primary source of truth. Relevant race, class, role, equipment, or incarnation files: [PATHS OR NONE].

Read every supplied file in full. Identify the exact selected world, continuity, timeline, and source medium. Research authoritative visual references when the setting is established fiction. Match the source's recognizable character design language, proportions, faces, linework, rendering, costumes, technology, materials, magic or power effects, and profile presentation.

Preserve the character's exact age, build, face, hair, eyes, skin, anatomy, clothing, equipment, social role, personality cues, and all deliberate player choices. Express those traits through the selected world's rules and visual language. Do not force an adventuring class to dominate the design when the world or character defines identity differently.

If an identity reference is supplied, preserve only the traits the player asks to retain. Do not copy unrelated clothing, pose, props, background, lighting, or style. Canon references may establish official design and style.

Use a natural pose that fits the character and world. Keep all important anatomy, clothing, and equipment visible. Use a background consistent with official profile art for that property; when no convention exists, use a simple unobtrusive background.

Optional override for this image only: [NONE]

No text, logos, UI, watermarks, incompatible adaptation designs, anachronistic clothing or technology, unsupported powers or equipment, copied unrelated reference details, accidental age or body changes, extra limbs, distorted hands, cropped feet, or any contradiction of the Markdown or canon.
```
