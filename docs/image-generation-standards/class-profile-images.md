# Class and Role Profile Image Standards

Use this standard for classes, professions, archetypes, power systems, ranks, and other broad roles used by the selected world.

## Required Output

- Square 1:1 image unless another format is requested.
- One representative figure or another presentation appropriate to the source material.
- Clear role, equipment, movement, and power cues.
- Visual style matched to the selected world's authoritative medium.
- No text.

Read the relevant Markdown in full. Do not assume every world uses fantasy adventuring classes, armor, spellcasting, Hit Dice, or a medieval visual vocabulary. For established fiction, research how the role actually appears in the correct continuity and era.

## Copy-Ready Prompt Template

```text
Create a square 1:1 profile image for the class, profession, archetype, rank, or role defined in [PATH OR NAME OF MARKDOWN].

Identify the exact selected world, continuity, timeline, and source medium. Research authoritative visual references when the role belongs to established fiction. Match the source's recognizable art direction and the canonical appearance, equipment, uniform, technology, movement, powers, limitations, and social function of this role.

Depict a broadly representative practitioner rather than a named character unless requested. Do not add subclass, specialization, faction, advanced-rank, or legendary features unless they are universal or explicitly required. Do not assume the subject is an adult, humanoid, magical, armed, or fantasy-based unless supported by the source.

Use the composition and background normally associated with official character or role art for the selected property. Where none exists, use a clear full-body presentation with an unobtrusive background.

Optional override for this image only: [NONE]

No text, logos, UI, watermarks, incompatible adaptation details, invented uniforms, unsupported weapons, armor, tools, powers, insignia, or technology, and no contradiction of the Markdown or canon.
```
