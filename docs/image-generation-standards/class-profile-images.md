# Class Profile Image Standards

Use this standard for base classes such as Vanguard, Warden, Mage, Channeler, and other broad adventuring disciplines.

## Required Output

- Square 1:1 image.
- One full-body representative practitioner from head to feet.
- Clear posture, equipment, movement, and role cues.
- Restrained atmospheric background rather than a full scene.
- No text.

The accompanying class Markdown is the complete source of truth. Read its Description, Hit Die, spellcasting fields, maximum spells known, class features, proficiencies, limitations, equipment implications, and all other established details before generating. Do not ask the user to repeat information already present there.

A base-class image represents the class as a broad role, not a named character, subclass, faction, profession, level-specific hero, or legendary exemplar. Do not add subclass-specific magic, colors, symbols, weapons, armor, techniques, or effects unless the optional override explicitly requests them.

## Copy-Ready Prompt Template

Replace only `[PATH OR NAME OF CLASS MARKDOWN]`. The optional override line may be deleted when no change is needed.

```text
Create a square 1:1 full-body class profile image for Kato using the accompanying class Markdown at [PATH OR NAME OF CLASS MARKDOWN] as the complete source of truth.

Read the entire Markdown before generating. Use the class's established identity, training, battlefield or expedition role, strengths, limitations, Hit Die, spellcasting status, class features, proficiencies, equipment implications, posture, movement, defensive habits, attack methods, and all other relevant details exactly as written. Infer only minor visual details necessary to render a complete representative image and never contradict the entry. Do not ask for information already contained in the Markdown.

Optional override for this image only: [NONE]

COMPOSITION
Show one broadly representative adult practitioner from head to feet, including footwear and all important equipment, with enough empty space to avoid cropping weapons, shields, tools, spell effects, clothing, or anatomy. Use a neutral but role-revealing standing pose and normal perspective. Keep the figure centered and dominant in frame. The pose may imply readiness, discipline, protection, study, channeling, mobility, or another established role, but must not become a dramatic action scene. Keep hands and tools visible where practical. Use a restrained cold-neutral background such as desaturated gray-beige, cold parchment, muted stone, charcoal haze, pale fog, or a subtle fog-dark gradient. Add only a faint floor shadow, low haze, or soft atmospheric grounding. Do not add a full landscape, interior, battlefield, unrelated props, other people, enemies, or a resolved action scene.

REPRESENTATIVE DESIGN
Depict the class itself rather than a named character, subclass, faction member, legendary champion, or specific profession unless the Markdown establishes those traits as universal. Use a plausible Kato adult whose clothing, equipment, stance, and physical readiness communicate the class's core role without implying that every member has the same face, race, gender, culture, wealth, outfit, weapon, or personality. Do not import subclass-specific magic, symbols, colors, mutations, weapons, armor, techniques, or effects into the base class image unless the optional override explicitly requests them.

When the class is non-spellcasting, do not add magical effects merely to make the image more dramatic. When the class is spellcasting, show only restrained base-class magic consistent with the Markdown rather than a named spell or subclass identity unless established.

ART DIRECTION
Use polished, clearly 2D dark-anime fantasy profile art with clean confident anime linework, controlled cel shading, restrained painterly detail, readable silhouettes, and cinematic but clear lighting. The image should feel cold, ancient, isolated, mysterious, dangerous, melancholic, and slightly dreamlike, matching Kato's northern world. The practitioner should appear capable and credible without becoming an exaggerated superhero, ornate fantasy champion, or generic action hero.

Use Kato's restrained northern palette of charcoal, slate, cold blue, weathered brown, moss green, iron gray, fog white, muted teal, and subdued amber accents. Materials must read clearly as wool, linen, leather, fur, wood, iron, bone, or other substances supported by the class Markdown. Visual emphasis should fall on the class's role, training, and practical capabilities rather than ornamentation. Any spellcasting or supernatural effect must accurately reflect the class's established spellcasting status and remain subtle and secondary unless the class description makes magic visually central.

CLASS FIDELITY
Preserve every established written trait and mechanic that has a meaningful visual implication. Clearly communicate the class's training, role, strengths, limitations, mobility, durability, weapon use, protective function, technical discipline, or magical practice through grounded visual cues. Do not invent unsupported proficiencies, armor, weapons, shields, spellbooks, holy symbols, tools, familiars, magical auras, class insignia, advanced-level features, future progression, or subclass powers.

Do not make the practitioner more glamorous, sexualized, muscular, youthful, mature, monstrous, heroic, ornate, wealthy, battle-worn, heavily armed, or battle-ready than the Markdown supports. Do not turn a general class portrait into a specific character portrait.

NEGATIVE REQUIREMENTS
No text, captions, labels, class names, logos, borders, UI, signatures, watermarks, fake letters, multiple figures, party lineup, named-character portrait, subclass-specific imagery, faction heraldry, advanced-level abilities, dramatic attack pose, active battle, full environment, photorealism, semi-realistic western fantasy, western comic style, chibi proportions, mascot-like design, glossy 3D rendering, generic AI-fantasy face, modern clothing, sci-fi props, random armor, unsupported weapons, excessive jewelry, random runes, neon glow, excessive magic, obscured anatomy, extra limbs, distorted hands, mismatched eyes, cropped head, cropped feet, cropped equipment, or any detail that contradicts the Markdown.
```
