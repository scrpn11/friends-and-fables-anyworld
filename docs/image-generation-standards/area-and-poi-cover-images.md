# Area and POI Cover Image Standards

Use this standard for settlements, buildings, interiors, landscapes, roads, ruins, and other locations.

## Required Output

- Square 1:1 environmental scene unless another format is requested.
- Accurate layout, architecture, terrain, technology, weather, lighting, and scale.
- Visual style matched to the selected world's authoritative medium.
- No text or map labels.

Read the Area or POI Markdown and the global standards in full. For an established fictional world, research official depictions of the location, region, architecture, technology, and era before generating. Use the correct continuity and timeline.

## Copy-Ready Prompt Template

```text
Create a square 1:1 environmental cover image for Anyworld using [PATH OR NAME OF AREA OR POI MARKDOWN] as the repository source of truth.

Identify the exact selected world, continuity, timeline, and intended medium. Research authoritative visual references when this is an established fictional setting. Match that source's recognizable environmental art direction, architecture, materials, technology, geography, lighting, color treatment, and level of detail.

Preserve every established spatial relationship, landmark, approach, boundary, terrain feature, building placement, material, hazard, and canonical detail. Where canon or the Markdown is silent, make only minor conservative inferences consistent with the selected world. Do not replace a specific canonical place with a generic fantasy, modern, science-fiction, or anime backdrop.

Show the location as a coherent usable environment. Choose a wide or medium-wide view appropriate to its scale. Small figures or vehicles may appear only as scale and life cues unless the entry requires a named subject.

Optional override for this image only: [NONE]

No text, captions, labels, map markers, logos, borders, UI, signatures, watermarks, incompatible adaptation details, anachronistic technology, invented landmarks, random monsters, resolved plot events, hidden essential layout, or any detail that contradicts the Markdown or canon.
```
